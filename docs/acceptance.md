# MVP 验收记录

版本：首版实现，2026-09-10。测试 fixture 均为合成数据，不能替代真实账单、真实支付或用户验收。

## 自动验证

| 范围       | 已执行的验证                                                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Go         | 全部包编译、单元测试；数据库集成测试与 `-race`                                                                                             |
| CSV/账本   | 12 位小数、重复三次不重复计费、金额更正与历史、事件键、无金额键的更正、未知列/敏感列、货币与时区解析、公式转义                             |
| Provider   | OpenAI Costs/Usage 分离；更正键稳定；Anthropic cents 与 cache 类别；OpenRouter BYOK 镜像排除；401/403/429/503；不完整分页不发布            |
| 身份与租户 | 真实 HTTP 一次性邮件验证；session/CSRF；Viewer 禁止写/计费；无 context 和另一 Workspace 的 RLS 读取为零；断开后历史保留；登出撤销          |
| 对账       | 原币种容差；缺失一日不能被确认为完整；Free 详情和导出服务端拦截；付费处理差异                                                              |
| Stripe     | HMAC/时间窗；事件 ID 去重；延迟失败事件读取当前有效订阅；宽限期以账单创建时间为准且不延长；取消撤销权益。HTTP transport 为合成 Stripe 返回 |
| Nuxt       | 两个应用的 typecheck 和 Cloudflare production build；官网三语言预渲染；三语言键一致；根域 308 不影响 app/api                               |

本地数据库验证使用 PostgreSQL WASM（PGlite）协议环境，包含非特权角色和 RLS。GitHub CI 配置 PostgreSQL 18.6 服务，重跑同一集成测试；以仓库 Actions 实际结果为准。没有运行浏览器视觉/交互自动化，不将编译成功记为三主题视觉验收。

## 本版产品限制

- 发票参考采用手录总额、范围与调整项，通用 CSV 可保存 Billed 口径；没有 PDF/OCR 或独立 invoice-line 文件解析器。
- L1 仅文本用量且需管理员输入价格版本；不支持自动核实全部非文本计费或自动模型映射。
- 图表的数值来自实际导入/同步；没有种入虚假的客户、账单或“已节省”数据。整体覆盖状态偏保守，当前日不承诺完整。
- 单一有效凭据主密钥，轮换需要重交凭据或后续双密钥迁移；没有把未经演练的轮换/灾备写为自动完成。
- 数据删除任务和保留期清理已实现，真实对象存储删除失败/恢复竞态仍需要部署环境演练。
- 不承诺达到完整七周项目的商业验收；本版用于运行闭环、接真实数据和进入设计伙伴验证。
