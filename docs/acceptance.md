# 上线检查

自动测试使用合成数据。测试通过不代表真实 Provider 金额、支付、投递、视觉效果或灾备已经验收。

## 自动测试范围

验证命令与 CI 工具统一见 [README](../README.md#验证)。

| 范围       | 验证内容                                                                             |
| ---------- | ------------------------------------------------------------------------------------ |
| CSV 与账本 | 小数精度、幂等导入、更正与修订、字段校验、币种/时区、公式转义                        |
| Provider   | Costs/Usage 分离、cents 换算、BYOK 排除、权限与重试、分页完整性                      |
| 身份与租户 | 邮件验证、session/CSRF、角色限制、跨 Workspace 隔离、RLS、登出与断开                 |
| 对账与导出 | 范围缺失、付费限制、差异处理、导出完成及中断恢复                                     |
| Stripe     | 验签/时间窗/版本、当前事件结构、去重与乱序、宽限期、取消、SDK 幂等重试、计划阶段参数 |
| Nuxt       | 三语言预渲染、路由表一致性、语言键、生产构建、根域 308、ESLint 与嵌套模板无障碍规则  |

## 发布前验收

- [ ] 使用三家真实管理凭据和去敏账单，按币种核对来源金额、费用回补、退款、税费、未知模型和月末/DST 窗口。
- [ ] 在 Stripe sandbox 完成 Checkout、失败支付、立即升级、期末降级、月/年周期切换、取消、Portal 和 Webhook 回放。
- [ ] 核对 Stripe 商户主体、税务、发票、退款规则和支持渠道；将 Terms/Privacy 草案替换为正式文本，再配置法律发布变量并启用 live。后端会在变量缺失时拒绝 live Stripe 启动。
- [ ] 验证 Cloudflare/Render 域名、TLS、私有 R2、生产密钥、日志脱敏与权限。
- [ ] 验证三语言邮件投递和 Google 授权回调；确认生产禁用开发登录入口。
- [ ] 演练 PostgreSQL/R2 同步恢复、删除清单重放和凭据主密钥恢复。
- [ ] 使用预期数据量与并发验证默认月窗口读 API 的 P95 < 1 秒，以及同步、导出和队列容量。
- [ ] 在桌面/移动端验证三语言、三主题、键盘操作、加载/错误状态与支付跳转。
- [ ] 邀请设计伙伴完成真实导入、对账、支付和反馈闭环。

## 产品边界

- CSV 为通用模板；Provider 专属模板须取得去敏样本后单独验证，不将未验证模板标为支持。
- 账单参考使用总额、范围和有证据的调整项；不解析 PDF/OCR 或独立 invoice-line 文件。
- L1 仅覆盖支持的文本用量与历史价格。价格由管理员录入有效期和证据，不自动认证全球实时价格。
- 价格比较不保证质量等价或实际节省，不提供 Gateway、自动切流、自动退款或 Prompt/Response 采集。
